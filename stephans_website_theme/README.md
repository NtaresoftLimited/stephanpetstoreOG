# Stephan's Website Theme

This is an isolated, local-only Odoo 20 website preview addon.

- Preview URL after an approved installation: `/stephans-preview`
- The page is created unpublished.
- The addon does not replace the current homepage, header, footer, products, or configuration.
- Featured product imagery is intentionally represented by local visual placeholders until exact existing Odoo product records and images are approved for mapping.
- Installation, deployment, activation, service restart, and database changes are outside this safe phase.
